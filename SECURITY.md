# Security Policy

## Supported Versions

The security updates are currently focused on the latest release of Cynthia AI Assistant.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a Vulnerability

We take the security of Cynthia AI Assistant seriously. If you find a security vulnerability, please do not report it in a public issue. Instead, report it privately.

To report a vulnerability:
1. Send an email to [insert contact email] detailing the vulnerability.
2. Include a description of the issue, steps to reproduce, and potential impact.
3. We will acknowledge receipt of your report within 48 hours and work with you to coordinate a fix and release.
