# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-12

### Added
- Initial release of Cynthia AI voice assistant with old Jarvis speed and capabilities.
- LiveKit WebRTC agent for low latency real-time voice channel interactions.
- Gemini Realtime API integration supporting key rotation and dynamic model fallback.
- Dynamic Memory System with structured facts, preferences, habits, scheduler, projects, and learning store.
- Device ecosystem server (FastAPI) enabling communication and visual control between the laptop (Master Brain) and remote devices (Android, etc.).
- Robust tools suites (WhatsApp automation, file manager, translation, project generation, vision, system volume/brightness control, and hand gesture modes).
- Kivy-based android GUI and client configuration.
